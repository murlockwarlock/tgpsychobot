# Плейсхолдеры служебного блока

Перед запросом к AI код заменяет плейсхолдеры в служебном блоке реальными данными. Если плейсхолдер удалён из шаблона, соответствующие данные в эту часть промпта не попадут.

## Доступные плейсхолдеры

- `{available_media_text}` — список медиафайлов активной темы и правила их использования.
- `{test_context_injection}` — резервная подстановка результатов завершённого основного и секретного тестов для старых записей без сохранённого блока истории. Новые результаты передаются как часть настраиваемого окна первых и последних сообщений независимо от анкеты. Во время отдельной генерации результата теста блок может намеренно отключаться, чтобы не дублировать данные.
- `{short_response_instruction}` — ограничение длины ответа, когда пользователь выбрал краткий формат.

Значения формируются в `ai_integration.py`, шаблон и подстановка находятся в `prompt_blocks.py`.
